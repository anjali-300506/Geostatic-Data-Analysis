# Geospatial Data Analysis

## Objective
Analyze location-based data to identify optimal areas for business expansion.

## Tools Used
- Pandas
- Scikit-learn
- Folium
- Google Colab

## Tasks Performed
- Visualized sales data geographically
- Identified demand hotspots
- Compared demand against store presence
- Recommended expansion regions

## Final Insight
High-demand regions with low store presence were identified as the best candidates for business expansion.
